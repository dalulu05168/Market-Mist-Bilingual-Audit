# 第二十三章 止损不是认输：它是投资者的安全带

许多投资者都声称自己始终会设置止损。

但真正到了执行止损的那一刻，他们突然变得异常有耐心。

入场之前，他们说：

“如果跌破这个位置，我就退出。”

买入之后，当价格真的跌破那个位置，他们却开始说：

“再等等，也许只是假跌破。”

“今天整个市场都弱，这次不算。”

“公司的基本面没有改变。”

“反正我是长期投资。”

“现在只亏一点，最终会涨回来的。”

结果，本来可以控制在很小范围的亏损，逐渐变成一场灾难。

市场上代价最昂贵的错误，不是判断出错。

判断出错再正常不过。

最昂贵的错误，是拒绝承认自己错了。

伊森·卡特真正学会执行止损，并不是在他亏损最大的一笔交易中。

恰恰相反。

他是在一笔只亏掉极少金额的交易里，学会了这件事。

那笔交易一点也不戏剧化。

没有令人兴奋的情节。

也没有赚到钱。

但它第一次让伊森明白了某个道理。

**止损不是失败。**

止损让你能够在市场中留得足够久，继续参与下一个机会。

## 一、一笔看起来近乎完美的交易

这只股票，我把它称为 Vega Cloud Infrastructure。

Vega Cloud Infrastructure 是一家欧洲云基础设施服务商，专注于企业云托管、混合云部署、数据备份安全和边缘计算解决方案。

它不是市场上最耀眼的云计算公司，但商业模式相当稳定。客户大多是中大型企业，收入中很大一部分来自长期合同和订阅服务。

当时，机构资金开始重新流入云基础设施板块。

主要有三个原因。

企业IT支出再次增加。

人工智能应用推动了对算力和数据存储的需求。

此外，经过长期调整后，多家云服务提供商的估值已经变得更加合理。

Vega Cloud 的走势图也很有吸引力。

经过长期下跌后，股票在42至48欧元之间整理了七周。

成交量逐渐萎缩。

20日均线趋于走平。

50日均线停止下行。

板块ETF跑赢大盘。

所有迹象都表明，这只股票正在为突破交易区间做准备。

伊森把它加入观察名单。

这次他没有冲动行动。

他填好了上一章讨论过的交易计划模板。

**交易逻辑：**云基础设施板块正在走强，Vega Cloud 形成七周交易区间，48欧元处有明确阻力。

**确认信号：**日线收盘高于48欧元，同时成交量超过20日平均水平。

**入场方式：**确认收盘突破阻力后建立少量仓位。只有在股价成功回测并守住48欧元时，才考虑加仓。

**止损条件：**如果价格重新跌回48欧元以下，并跌破突破当日低点，就视为突破失效。

**最大风险：**账户总资金的0.7%。

**第一目标：**52欧元。

**第二目标：**根据交易区间计算的量度升幅，约54欧元。

看完他的计划，我说：

“这是一份准备充分的交易计划。”

伊森笑了。

“这次你终于没有先批评它。”

“别太肯定。”我回答，“市场会替我来批评。”

当时，他以为我在开玩笑。

市场很快证明并非如此。

## 二、一次成功突破几乎立刻失败

周三，Vega Cloud 伴随强劲成交量突破48欧元。

这次突破十分漂亮。

上午股价升至48欧元之上。

整个下午都维持在这个水平以上。

最终收于49.10欧元。

成交量比20日平均水平高出约50%。

按照交易计划，伊森建立了仓位。

仓位规模不大。

因为仍在等待成功回测，他没有加仓。

第二天，股价继续上行，触及49.80欧元。

一切看起来都完全按照计划展开。

伊森保持冷静和纪律。

但到了第三天，整体市场开始走弱。

科技板块回调，多家云计算公司同时下跌。

Vega Cloud 低开，迅速回落到48.40欧元。

伊森看着自己的交易计划。

“还在48欧元之上。”

“没错。”

上午11点，股价下探到48.05欧元。

下午，终于跌破48欧元。

但盘中跌破支撑，并不自动意味着突破失败已经得到确认。

伊森早就理解这一点。

他没有急着卖出，而是等待收盘表现。

交易结束前最后三十分钟，Vega Cloud 没能重新站上48欧元。

相反，它进一步跌至47.60欧元。

更重要的是，股价也跌破了突破当日的最低价。

成交量明显放大。

他的交易计划明确写着：

如果价格重新跌回48欧元以下，并跌破突破当日低点，则突破失败。

现在，全部条件都已经满足。

他必须卖出。

可真正到了这一刻，他还是犹豫了。

鼠标停在“卖出”按钮上。

“也许只是整体市场正在回调。”他说。

我保持沉默。

他接着说：

“公司的基本面没有改变。”

我仍然没有说话。

然后他又补充：

“亏损还不大，要不要再给它一天？”

我看着他。

“你是在分析市场，还是在向市场求情？”

这个问题立刻让他停了下来。

他低下头，重新看了看交易计划。

然后卖出了。

亏损很小。

账户下降约0.7%，恰好符合此前的风险计划。

但他看上去并没有如释重负。

因为执行止损从来不会令人舒服。

哪怕很小的亏损，在情绪上也不好受。

使用止损最难的部分，并不是技术分析。

而是愿意亲手承认：

这一次，我判断错了。

## 三、止损之后，最难的考验才开始

第二天，Vega Cloud 反弹了。

这是市场最喜欢的心理陷阱之一。

伊森退出后的第二天，Vega Cloud 从47.40欧元反弹至48.20欧元。

虽然仍未真正收复突破位置，但股价确实上涨了。

伊森盯着屏幕，脸色沉了下来。

“如果昨天没卖，现在亏损已经更小了。”

我问：

“所以……你后悔卖出了吗？”

他没有立即回答。

长时间沉默后，终于说：

“有一点。”

“这完全正常。”

股票在你止损后立即反弹，是每位交易者都要面对的最艰难的心理考验之一。

你会开始觉得自己卖得太早。

你会怀疑止损是否设得太严格。

你会想重新买回这只股票。

而且逐渐忘记最初为什么触发止损。

然后我告诉伊森：

“不能仅凭止损后第二天股价怎么走，就判断止损是否正确。”

他看着我。

我继续说：

**“判断止损是否正确，唯一正确的方式，是看它是否符合你的交易计划。”**

Vega Cloud 最初的买入逻辑是突破交易区间。

股价重新跌回区间。

还跌破了突破日低点。

这就意味着突破已经失败。

只要这套交易逻辑仍然成立，执行止损就是正确的决定。

即使第二天股价反弹，也不能证明前一天的止损是错误的。

因为反弹本身，也可能变成一次失败的回测。

真正的问题是：

股价能不能重新站上48欧元？

能不能伴随放量恢复上涨？

能不能再次突破，并真正得到市场认可？

如果不能，那么昨天的止损就恰好完成了自己的职责。

它保护了他的资金。

[图23-3：止损之后短暂反弹，但未能收复原突破位。图示强调，不能根据次日股价涨跌判断止损决策是否正确。]

事实证明，第三天 Vega Cloud 又下跌了。

这一次跌至46.20欧元。

第四天继续跌至45欧元。

第五天，即使整体市场反弹，Vega Cloud 也只回升到46.50欧元，仍远低于最初的突破位。

看着走势图，伊森终于松了一口气。

“如果没有止损，现在亏损就大得多了。”

“正是如此。”

“而且我大概还会不断编造理由，让自己继续持有。”

“这才是最大的风险。”

许多投资者不是输在第一笔亏损交易上。

他们输在亏损之后为自己找的解释上。

他们不愿接受止损，于是被迫创造新的理由。

最初，这是一次突破交易。

突破失败后，它突然变成了长期投资。

随着股票继续下跌，它又变成了价值投资。

跌得更深时，它就成了一个只能“等回本”的仓位。

一步步地，原有的交易逻辑已经被扭曲得面目全非。

最终，他们管理的已经不是仓位。

而是自己的情绪。

## 四、正常回调与形态失败的区别

伊森问了一个非常重要的问题。

“我怎样才能分清正常回调和形态失败？”

每个交易者都必须回答这个问题。

因为止损太宽松，会让亏损不必要地扩大。

止损太紧，又会让普通的市场波动把你从原本很好的交易中赶出去。

我在白板上画了两张图。

左边是健康回调。

股价突破48欧元后，在较小成交量下回落。

下跌在48欧元附近停止。

股票重新收在突破位之上，随后继续上涨。

右边则是假突破。

股价突破48欧元后，重新跌破突破位。

成交量放大。

股价跌破突破日低点。

之后试图收复48欧元，却以失败告终。

两张图只差几根K线。

但含义截然不同。

健康回调的决定性特征是：

**关键价格位受到考验，但最终成功守住。**

形态失败的决定性特征是：

**关键价格位失守，而且市场无法重新收复。**

[图23-4：健康回调与失败形态的对比。左侧在缩量回调时成功守住突破位，随后继续上行；右侧放量跌回区间，并且无法重新站上突破位置。]

我告诉伊森：

“触发止损，不是因为价格下跌，而是因为你入场的理由已经失效。”

如果你因为突破而买入，那么重新跌破突破位，就是警告信号。

如果你因为回调而买入，那么跌破回调低点，就是警告信号。

如果你买的是牛旗突破，那么跌回旗形内部，就是警告信号。

如果买的是双重底突破，那么跌回颈线下方，就是警告信号。

如果你是在上升趋势的回调中买入，那么趋势结构和关键均线遭到破坏，就是警告信号。

止损必须始终对应你的入场理由。

与交易逻辑无关的止损，只是一种随机退出。

随机止损会反复把你震出本来不错的交易。

但完全不使用止损，则可能让一次错误把整个账户拖入灾难。

## 教授的白板课堂

### 失败形态与止损执行

那天晚上，我和伊森的白板课题是“失败形态与止损执行”。

我在白板上写下的第一句话是：

**止损不是预测未来，而是承认当前的交易逻辑已经失效。**

很多交易者误解了止损的用途。

他们以为使用止损就意味着：

“我认为这只股票以后永远不会再涨。”

“我承认这家公司不好。”

“我承认自己失败了。”

“我把账面亏损变成了实际亏损。”

这些理解都不正确。

止损只意味着一件事。

市场已经证明，你当初进入交易的理由不再成立。

股票未来是否最终上涨，与这笔具体交易现在是否应该继续持有，完全是两回事。

### 一、什么是形态失败？

形态失败，是指价格没有沿着图表形态所暗示的方向发展，反而回到形态的关键价位，或突破这些关键价位，从而使最初的交易逻辑失效。

常见的例子包括：

- 股价突破交易区间后又跌回区间内。
- 突破颈线后失败，并重新跌回颈线下方。
- 牛旗形态突破后，又跌回旗形内部。
- 双重底突破后，重新跌破颈线。
- 头肩底突破后，重新跌回颈线下方。
- 双重顶跌破颈线后，又迅速收复颈线。

形态失败，不是普通的价格波动。

它意味着关键市场结构已经失效。

因此，每次入场之前都必须知道：

确认位在哪里？

失效位在哪里？

哪些波动只是正常的价格起伏？

而到什么位置时必须退出？

### 二、三种止损方式

止损大致可以分成三类。

**1. 结构性止损（Structural Stop-Loss）**

这是最重要的止损类型。

它以市场结构为依据。

例如：

- 跌破支撑位。
- 重新跌回交易区间。
- 跌破颈线。
- 跌回牛旗形态内部。
- 跌破前一波段低点。

结构性止损最大的好处，是它直接对应最初的交易逻辑。

**2. 账户风险止损（Account Risk Stop-Loss）**

这类止损根据整体账户风险决定。

例如，把单笔交易的最大损失限制在总账户权益的0.5%、1%或2%。

它的目的是避免一笔交易给账户造成重大伤害。

**3. 时间止损（Time Stop-Loss）**

有时，交易始终没有触及价格止损位，却也没有按原计划发展。

如果突破之后，股价在较长时间内无法继续上涨，成交量不断缩小，板块转弱，资金利用效率下降，那么退出交易也许是适当的。

时间止损适用于那些并没有亏太多钱，却同样没有按照原计划发展起来的交易。

### 三、为什么必须在入场前写下止损？

止损必须在入场之前确定。

绝不能等到入场之后。

原因很简单。

建立仓位之前，你的判断相对客观。

建立仓位以后，你的持仓会开始影响思考方式。

持有一只股票，会改变大脑处理信息的方式。

你会更加愿意相信利好消息。

你会更容易忽视警告信号。

你会把普通反弹解释成希望。

你会把明显的跌破解释成暂时洗盘。

这就是为什么止损必须提前写好。

写下来，并不能彻底消除情绪。

但当情绪不可避免地出现时，你就有一个客观标准可以回到那里。

我告诉伊森：

“止损不是市场开始下跌后才需要的工具。它是你出发之前就应该系好的安全带。”

没有人会等汽车撞上墙之后才系安全带。

### 四、为什么小额亏损如此重要？

小额亏损只是经营交易事业的正常成本。

巨额亏损则是灾难。

小额亏损不会毁掉你的账户。

巨额亏损却可能摧毁信心。

一连串小额亏损，可以分析、复盘和修正。

而一次灾难性亏损，可能永久损害你执行交易系统的能力。

我给伊森看了一张简单的表。

亏损10%，需要再上涨约11%才能回本。

亏损20%，需要上涨25%。

亏损30%，需要上涨约43%。

亏损50%，需要上涨100%。

亏损越大，恢复起来就越困难。

所以止损并不只是一种保守工具。

它也是你进攻能力的一部分。

只有保护好资金，你才保留了把握未来机会的能力。

[图23-7：通过表格或柱状图，比较小幅与大幅亏损所需的回本涨幅，说明亏损幅度与回本涨幅之间的非线性关系。]

伊森看着那张表。

“所以止损真正保护的不是这一笔交易，而是整个账户。”

“正是如此。”

“如果任由每次亏损不断扩大，即使我好几次判断正确，一次错误也可能抹掉所有收益。”

“风险管理的核心就是这个。”

### 五、止损之后如何复盘？

止损不代表整个交易流程结束。

每次止损后，都应当进行复盘。

但复盘不是为了责备自己。

它应该回答五个问题。

第一，最初的交易逻辑是否合理？

第二，确认信号是否足够？

第三，止损位置设置得是否适当？

第四，交易是否按照计划执行？

第五，下一笔交易前，是否需要改进某些交易规则？

如果交易逻辑合理、止损位置适当、执行符合计划，那么这次亏损就是**合格的亏损**。

合格的亏损不值得后悔。

它只是一个正常运行的交易系统不可避免的一部分。

真正值得认真警惕的，是不合格的亏损。

例如：

- 没有计划就进入交易。
- 股价已经远离合理位置后仍去追涨。
- 入场前没有确定止损位。
- 明知失效位置已经跌破，仍拖延退出。
- 仅仅因为亏损，就把短线交易改称长期投资。

亏损本身并不可怕。

失去控制的亏损才可怕。

## 案例复盘：为什么 Vega Cloud 的止损是正确决定？

现在回到 Vega Cloud Infrastructure。

这笔交易最终以亏损告终。

但它仍然是一笔合格交易。

理由很直接。

第一，建立仓位前已经制定完整交易计划。

第二，突破信号当时确实成立：股价伴随放量，收于48欧元上方。

第三，仓位得到合理控制，账户最大风险事先已经明确。

第四，止损直接对应最初的交易逻辑。

第五，股价重新跌破48欧元，并跌破突破日低点，使突破逻辑失效。

第六，伊森严格按照计划执行。他没有因为交易走得不顺，就把短线突破交易改成长期投资。

第七，股票此后继续下跌，进一步证明止损至少避免了一笔更大的亏损。

即便股价最后真的重新上涨，也不能否定这次止损。

因为止损的目的不是卖在绝对最低点，也不是预测未来。

它的目的是在原有交易逻辑失效之后，保护你的资金。

这笔交易给伊森最大的收获，不只是“少亏了一点”。

而是远比这重要的东西。

他第一次亲手执行了一项虽然令人不舒服、却毫无疑问正确的决定。

这一课比盈利更加有价值。

因为有些利润可能来自运气。

纪律只能来自遵守交易计划。

## 本章交易规则

那天，我要求伊森写下七条规则。

**规则一：**止损不是承认失败。原有交易逻辑失效之后，按计划退出才是正确选择。

**规则二：**每一笔交易都必须在入场前明确止损，绝不能在事后临时编造。

**规则三：**止损必须与入场理由相对应，不能随意设置。

**规则四：**正常回调是在测试关键价位；形态失败则是失去关键价位。

**规则五：**止损后出现暂时反弹，并不代表止损是错误的。

**规则六：**小额亏损是交易的正常成本。真正毁掉账户的是巨额亏损。

**规则七：**每次止损后都要复盘，区分合格亏损与不合格亏损。

随后我又补充了一句话：

“止损不是为了证明你错了，而是为了防止一次错误变成无法挽回的灾难。”

伊森把它记进笔记本。

然后写下自己的话：

“小额亏损，让我还能继续留在市场里。”

小额亏损，使我能够继续参与下一次机会。

这是他在第二十三章里真正获得的成长。

## 本章总结

在这一章里，伊森·卡特学会了执行止损的真正意义。

他理解了：

交易计划不是为了保证盈利。

交易计划的存在，是为了在市场不配合时，你清楚知道应该做什么。

止损不是情绪决定。

而是逻辑决定。

当突破失败、颈线跌破、牛旗形态崩溃、支撑失守，或者市场否定了最初的交易逻辑时，退出才是正确决定。

从这一章开始，伊森不再把止损看作失败。

他开始把止损视作账户安全系统的一部分。

他明白：

只要亏损仍处于控制之中，下一次机会就仍然存在。

只要资金得到保全，就永远还可以作出下一次决定。

只要纪律依旧完整，就还没有发生真正的失败。

下一章，伊森将进一步深入风险管理的另一个领域：

**仓位规模管理。**

他将发现，两名交易者可能找到完全相同的机会——

却有一个获得稳定利润，另一个毁掉了账户。

差别往往不在分析，

而在仓位大小。
