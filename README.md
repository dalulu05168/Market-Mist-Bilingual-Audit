# 《市场迷雾》Market Mist — 中英文翻译核对

本仓库为用户指定的 **GitHub 公开仓库**，用于存放英文原书资料与中文译稿、记录校对问题。**中文译稿均属待审稿，尚未逐句验收，不是准确性已验证的最终版本。**

## 文件目录

- `original/chapters_en/` 英文原文按章节拆分的辅助文本（以英文 PDF 原文为最终依据）
- `translations/chapters_zh_draft/` 中文28章待审译稿
- `audit/` 核对记录与待解决问题
- `AGENTS.md` 自动审校流程和约束

## 终审标准

逐段逐句核对英文和中文，排查漏译、误译、擅自增删、姓名、价格、百分比、时间、专业术语与逻辑方向等问题。查错、修订、复核后才标记验收通过。**图表内部英文无须汉化，保留原始图像。**
